# Public Assets

This directory contains public assets used by the example application.

## Sample PDF

To test the demo application, place a sample PDF file here:

```
public/sample.pdf
```

You can use any PDF file for testing. Some suggestions:
- Download a sample PDF from the internet
- Use a test document from your system
- Generate a simple PDF using online tools

The demo application will reference this file for testing PDF thumbnail generation.

## Note

The `sample.pdf` file is not included in the repository to keep it lightweight.
You need to add your own PDF file for testing purposes.
